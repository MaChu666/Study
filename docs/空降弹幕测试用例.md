# 空降弹幕测试用例

> 判定规则（`bil-frontend/src/components/video/VideoPlayer.vue` 中 `isValidJumpDanmu`）：
> 1. 输入必须**整体**匹配 `^\[空降\]\d{1,2}:\d{2}$`（首尾允许空格，会先 `trim`）
> 2. 秒数必须 ≤ 59（正确时间格式）
> 3. 换算后的总秒数必须 ≤ 视频时长（`totalSeconds > duration` 即失败）
> 4. 满足以上全部条件 → 空降弹幕（`danmuType=1`，青色 `▶ MM:SS`，点击跳转）；否则 → 普通弹幕

## 一、判定为空降弹幕（正向用例）

| # | 弹幕内容 | 视频时长 | 预期 | 说明 |
|---|---------|---------|------|------|
| 1 | `[空降]1:13` | 任意 ≥ 73s | 空降 | 基础用例，跳转 1:13 |
| 2 | `[空降]12:34` | 任意 ≥ 754s | 空降 | 分钟 2 位 |
| 3 | `[空降]0:12` | 任意 ≥ 12s | 空降 | 分钟 1 位且为 0 |
| 4 | `[空降]00:00` | 任意 | 空降 | 跳到视频开头 |
| 5 | `[空降]0:00` | 任意 | 空降 | 同上 |
| 6 | `[空降]59:59` | 任意 ≥ 3599s | 空降 | 分钟上限内最大值 |
| 7 | `[空降]99:59` | 任意 ≥ 5999s | 空降 | 分钟 2 位上限（99） |
| 8 | ` [空降]1:13 ` | 任意 ≥ 73s | 空降 | 首尾空格被 trim 后合法 |
| 9 | `[空降]1:13` | 恰好 73s | 空降 | 时间等于时长（边界相等合法） |

## 二、不会被判定为空降弹幕（负向用例，全部按普通弹幕输出）

### A. 前缀缺失 / 格式错误

| # | 弹幕内容 | 失败原因 |
|---|---------|---------|
| 10 | `1:13` | 没有 `[空降]` 前缀 |
| 11 | `空降1:13` | 缺方括号 |
| 12 | `空降]1:13` | 缺左方括号 |
| 13 | `[空降1:13` | 缺右方括号 |
| 14 | `[空降]` | 前缀后没有时间 |
| 15 | `[空降] ` | 前缀后只有空格 |
| 16 | `12[空降]0:12` | 前缀不在开头 |
| 17 | `哈哈[空降]1:13` | 前缀前有其他内容 |
| 18 | `[空降][空降]1:13` | 前缀重复 |

### B. 前缀后带多余内容

| # | 弹幕内容 | 失败原因 |
|---|---------|---------|
| 19 | `[空降]1:13aw` | 时间后有字母 |
| 20 | `[空降]0:12 大大` | 时间后有中文/空格 |
| 21 | `[空降]1:13！` | 时间后有标点 |
| 22 | `[空降]1:13 @user` | 时间后有艾特内容 |
| 23 | `[空降]1:13哈哈` | 时间后直接接中文 |

### C. 时间格式错误

| # | 弹幕内容 | 失败原因 |
|---|---------|---------|
| 24 | `[空降]0:1` | 秒只有 1 位 |
| 25 | `[空降]1:2` | 秒只有 1 位 |
| 26 | `[空降]0:122` | 秒有 3 位 |
| 27 | `[空降]0113` | 缺少冒号 |
| 28 | `[空降]1 13` | 用空格代替冒号 |
| 29 | `[空降]100:13` | 分钟有 3 位 |
| 30 | `[空降]:13` | 缺少分钟 |
| 31 | `[空降]1:` | 缺少秒 |
| 32 | `[空降]1:1:3` | 冒号超过一个 |
| 33 | `[空降] 1:13` | 前缀后紧跟空格 |
| 34 | `[空降]1 :13` | 分钟和冒号之间有空格 |
| 35 | `[空降]1: 13` | 冒号和秒之间有空格 |
| 36 | `[空降]1：13` | 全角冒号 |
| 37 | `[空降]1.13` | 小数点分隔 |
| 38 | `[空降]-1:13` | 负数 |
| 39 | `[空降]+1:13` | 正号 |
| 40 | `[空降]1a:13` | 分钟混入字母 |
| 41 | `[空降]1:1a` | 秒混入字母 |
| 42 | `[空降]１:１３` | 全角数字 |

### D. 时间值非法（秒 > 59）

| # | 弹幕内容 | 失败原因 |
|---|---------|---------|
| 43 | `[空降]0:60` | 秒 = 60 |
| 44 | `[空降]0:99` | 秒 = 99 |
| 45 | `[空降]1:61` | 秒 = 61 |

### E. 超出视频时长

| # | 弹幕内容 | 视频时长 | 失败原因 |
|---|---------|---------|---------|
| 46 | `[空降]1:14` | 73s（1:13） | 74s > 73s |
| 47 | `[空降]90:00` | 60 分钟 | 5400s > 3600s |
| 48 | `[空降]99:59` | 30 分钟 | 5999s > 1800s |
| 49 | `[空降]59:59` | 30 分钟 | 3599s > 1800s |
| 50 | `[空降]0:12` | 11s | 12s > 11s |

## 三、边界说明

| 场景 | 结果 |
|------|------|
| `[空降]1:13` 且视频恰为 73s | 空降（`>` 才判超时，相等合法） |
| `[空降]1:14` 且视频恰为 74s | 空降（相等合法） |
| `[空降]0:00` | 空降，点击跳到 0:00 |
| 输入框为空 / 全空格 | 不触发发送（`sendDanmu` 先行拦截） |
| `[空降]1:13` 后带换行 | 输入框为单行，实际不会出现；若存在换行则不匹配 `$` 语义需注意（JS 中 `$` 可匹配末尾换行前，建议以单行输入为准） |

## 四、验证方法

在视频页发送栏输入弹幕并观察行为：

1. **空降弹幕**：发送后本地立即出现青色 `▶ MM:SS`；刷新页面后重新加载仍显示 `▶ MM:SS`（`danmu_type=1` 已入库）；播放到其它时间后点击该弹幕 → 跳转到对应时间
2. **普通弹幕**：发送后按普通弹幕显示（用户所选颜色/字号/模式），点击弹出「复制 / 举报」菜单；刷新后仍为普通弹幕
3. 数据库核对：`SELECT danmu_id, text, danmu_type, time FROM danmu_info ORDER BY danmu_id DESC LIMIT 10;` —— 空降弹幕 `danmu_type=1`，普通弹幕 `danmu_type=0`
