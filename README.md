# BilBil

模仿 B 站的在线视频分享网站。

## 项目技术栈

### 后端
- Spring Boot
- MyBatis
- MySQL
- Redis
- Elasticsearch

### 前端
- Vue 3 + Element Plus + Pinia + Mitt

## 系统架构

系统采用 Spring Boot 单服务架构。`bil-common` 为公共模块，包含实体类、Service、Mapper、Redis 操作等共享代码；`bil-web` 为前台接口模块；`bil-admin` 为后台接口模块。各模块共享同一 Spring Boot 应用，通过不同端口或路径区分前后台服务。

## 功能模块

### 账号模块
- **注册**：用户填写邮箱、用户名、密码，配合验证码完成注册，密码采用 MD5 加密存储。
- **登录**：用户通过邮箱和密码登录，登录成功后返回 Token（存 Cookie + Redis），后续请求通过 Token 保持会话。
- **自动登录**：前端读取 Cookie 中的 Token，后端校验 Redis 中的 Token 有效性，未过期则自动续期。
- **退出登录**：清除 Cookie 和 Redis 中的 Token。

### 主站模块
- **视频列表展示**：按分类展示视频，支持分页加载。
- **视频详情**：视频播放、评论、点赞、收藏、弹幕、投币等互动功能。
- **推荐视频**：基于当前视频标题，通过 Elasticsearch 分词技术，智能推荐相似视频。
- **热门视频**：按播放量排行展示热门视频。

### 创作中心模块
- **发布视频**：支持分片上传，使用 Redis 消息队列异步处理视频合并、转码和切割 TS 分片。
- **数据统计**：图表展示粉丝、播放量、评论、弹幕、点赞、收藏、投币的总数及近一周趋势。
- **互动管理**：评论管理和弹幕管理功能。
- **视频系列**：创建、编辑、删除视频系列，管理系列中的视频排序。

### 视频播放模块
- **分片播放**：视频以 TS 分片 + m3u8 索引形式提供，支持流畅播放。
- **弹幕**：用户可发布、查看弹幕，管理员可删除违规弹幕。
- **在线人数**：实时统计并上报视频在线观看人数。

### 用户中心模块
- **个人信息展示**：关注数、粉丝数、获赞数、播放数等信息。
- **投稿视频管理**：管理自己上传的视频。
- **关注/粉丝管理**：查看关注列表和粉丝列表，支持关注/取消关注。
- **播放历史**：记录和清除视频播放历史。
- **消息中心**：未读消息数、消息列表、已读/删除消息。
- **收藏**：查看收藏的视频列表。
- **主题设置**：保存用户主题偏好。

### 搜索模块
- **视频搜索**：利用 Elasticsearch + IK 分词器，快速检索视频。
- **搜索热词**：通过 Redis incrementScore 实时记录热词搜索次数。

### 管理后台模块
- **分类管理**：新增、修改、删除、排序视频分类。
- **视频管理**：审核用户上传的视频，对违规视频进行删除，推荐优质视频。
- **用户管理**：查看用户列表，修改用户状态（启用/禁用）。
- **系统设置**：设置文件上传大小、评论限制、弹幕限制等系统参数。
- **数据统计**：实时统计总数和按周统计趋势。
